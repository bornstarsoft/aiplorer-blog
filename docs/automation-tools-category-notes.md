Future Automation Tools pages should follow the same draft-first workflow used
for other Aiplorer tool pages:

- Add one draft tool page at a time.
- Keep `draft: true` until official sources are reviewed.
- Avoid exact pricing, plan limits, app counts, integration details, task
  limits, workflow limits, AI feature availability, API claims, security
  guarantees, and enterprise availability unless directly verified and needed.
- Include caution notes about automation reliability, app permissions, connected
  accounts, customer data, business data, workflow failures, and changing
  availability.
- Publish only after manual review and validation.

## 2026-07-25 Source Freshness Review

All seven reviewed Automation Tools pages were rechecked against current
official product, pricing, help or documentation, and security or privacy
sources.

Zapier, Make, n8n, IFTTT, and Pipedream retained their cautious high-level
descriptions. Bardeen's wording was narrowed to match its current emphasis on
research, data, and business workflows.

Relay.app is a status exception. Its official site now announces that access
will end on August 15, 2026 for free users and September 14, 2026 for paying
customers. The reviewed page remains public at its existing URL, but now
functions as a transition notice for existing users and points them to official
shutdown and export guidance. It is not presented as a tool for new adoption.

The review continued to avoid exact prices, changing limits, app counts,
feature availability promises, security guarantees, and data handling
guarantees. Users are reminded to test workflows, review permissions and
connected accounts, protect customer and business data, and verify migration
results before relying on automation.
