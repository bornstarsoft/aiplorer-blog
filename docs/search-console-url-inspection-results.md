## Inspection Procedure

1. Confirm the authenticated property is the `aiplorer.com` domain property.
2. Process URLs in priority order and stop when the daily quota is reached.
3. Record the inspection date, indexed or not-indexed result, user-declared
   canonical, Google-selected canonical, last crawl time, page fetch issue,
   live-test result when run, and action taken.
4. Request indexing only for an intended public URL whose rendered page,
   canonical, and sitemap behavior are correct.
5. Record `No action` when the result is expected or when recrawling should be
   allowed before another request.

Do not record account email addresses or other authentication details in this
file.
