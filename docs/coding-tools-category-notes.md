# Coding Tools Category Notes

Date: 2026-06-11

The Coding Tools category now has five reviewed representative pages:

- GitHub Copilot
- Cursor
- Windsurf
- Replit
- Tabnine

These tools are presented as reviewed examples for code drafting, code review,
project editing, debugging support, and developer workflows. The category page
does not rank tools, assign ratings, or claim that any tool is best.

Coding tool pages should continue to use cautious wording. Users should review
generated code, test changes before production use, protect secrets and private
repositories, check licenses and workplace policy, and verify security-sensitive
changes carefully.

Future Coding Tools candidates should remain draft-first until official sources
are checked. Official review should avoid unsupported claims about pricing,
plan limits, model access, IDE availability, repository access, enterprise
availability, data handling, license safety, completion quality, or feature
availability.
