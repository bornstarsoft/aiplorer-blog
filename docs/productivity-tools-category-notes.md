# Productivity Tools Category Notes

Date: 2026-07-25

The Productivity Tools category currently has six reviewed representative
pages:

- ChatGPT
- Claude
- Gemini
- Perplexity
- Microsoft Copilot
- Notion AI

These tools are presented as reviewed examples for writing, summarizing,
brainstorming, research support, note organization, and everyday productivity
workflows. The category page does not rank tools, assign ratings, or claim that
any tool is best.

Productivity tool pages should continue to remind users to review generated
summaries, drafts, answers, and recommendations before publishing, sending, or
using them for decisions. Important facts and original sources should be
verified. Private, confidential, customer, employee, legal, medical, and
financial information requires extra care.

Future Productivity Tools candidates should remain draft-first until official
sources are checked. Official review should avoid unsupported claims about
pricing, plan limits, model access, connected-product behavior, integrations,
privacy or security guarantees, data handling, accuracy, or exact feature
availability.
