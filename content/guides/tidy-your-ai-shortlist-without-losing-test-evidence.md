## Start With A Smaller View

A long saved list does not mean every candidate needs attention today. In
[your shortlist](/ai-tools/shortlist/), use a stage or test-date view to focus
on the next decision. A filter hides other candidates; it does not remove
their evidence. Return to **All** when you need the complete list.

Keep a candidate when you still have a specific unanswered question. A
decision stage records your workflow, not a recommendation or a score.
Do not clear a useful evaluation just to make the page look finished.

## Preserve What You May Need Again

Before removing a candidate or clearing the list, keep the task, actual
observation and unresolved question in an approved location. For example,
this fictional reminder is more useful than simply writing "not useful":

> Tested three invented requests. The draft missed one missing-value flag.
> Revisit only if the next trial preserves unknown fields without guessing.

This is an editorial example, not a result from a named service. Record
your own evidence and avoid secrets or confidential content in browser notes.

A **Download backup** JSON file preserves restorable shortlist state,
including private notes. Keep it private. A **Download brief** is a readable
snapshot, not a restore file, and excludes private notes by default.
Use the [sharing checklist](/guides/review-an-ai-tool-decision-brief-before-sharing/)
before sending a brief to anyone else.

## Understand What Clear Removes

**Clear shortlist**, inside **Export, backup and restore**, asks for
confirmation. It clears all saved candidates in this browser, including
those hidden by filters, along with their notes, checks, stages and test
dates. The stage and date views return to **All**.

Cancel keeps the data. If another tab changes the stored evaluation while
the confirmation is open, the clear is stopped so you can review the new
state. Close other Aiplorer tabs before retrying. If saving fails, follow the
message rather than assuming the clear completed.

This action does not clear announcement read status or reset-history
checkpoints. It is not a way to erase all browser data, remove a vendor
account or cancel a subscription. There is no built-in undo; a previously
downloaded JSON backup can be [restored separately](/guides/move-your-ai-shortlist-to-another-browser/).
Restore replaces the current evaluation rather than merging old and new work.

## Leave A Reason To Return

Keep one next question for each candidate you retain: an output to check,
a permission to understand, or a plan condition to confirm on the official
site. Return when that question matters, not just to complete checked boxes.

If you only need another test, use the
[evaluation restart guide](/guides/restart-an-ai-tool-evaluation-without-losing-context/)
instead of deleting the whole list. A new test should preserve what you
learned before it.
