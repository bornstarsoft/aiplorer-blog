## Fix One Audible Problem First

Auphonic's [algorithm guide](https://auphonic.com/help/algorithms/) describes
tools for post-production rather than live calls. Start with a short
recording you have permission to upload, such as a scripted draft read by
two volunteers. Mark where one voice is hard to hear and where the music
or room tone should remain. Compare the original and export at a similar
playback level so that a louder output does not automatically sound better.

## Carry Forward the Settings, Not the Assumptions

If a sample passes, save the settings using the documented
[preset workflow](https://auphonic.com/help/web/preset.html). Review the
metadata and any destinations a preset carries before applying it to a new
file. Keep publishing destinations disconnected for the first trial.
Recheck quiet speech, music, and transitions whenever the recording setup
changes.

Auphonic is not a backup service. Keep the original and the approved export
in your own storage, and read its [terms](https://auphonic.com/terms_of_service),
[privacy policy](https://auphonic.com/privacy), and [pricing](https://auphonic.com/pricing).
Use the [audio cleanup practice pack](/use-cases/check-an-ai-audio-cleanup-against-a-brief/)
to practice deciding which changes preserve the intended sound.
