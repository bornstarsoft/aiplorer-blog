## Start From a Sketch You Can Share

The [Krea Academy walkthrough](https://www.krea.ai/enterprise/academy/intro-to-krea)
shows how its Realtime canvas updates an image as the sketch changes. For
a first trial, draw a fictional display stand using simple shapes. Make
two versions with different placements, but keep the product outline and
space for the headline fixed. Save the version that best follows the brief,
not just the one that looks most realistic.

## Keep a Baseline for the Next Review

Save the original sketch, the preview you chose, and one change to test
next time. When you return, compare a new draft against those references.
Check for changed proportions, unreadable text, and missing constraints
before handing it off. The
[image edit practice pack](/use-cases/check-an-ai-image-edit-against-a-brief/)
lets you rehearse those checks using a fictional brief.

Read the current [plans](https://www.krea.ai/pricing),
[terms](https://www.krea.ai/terms), and [privacy policy](https://www.krea.ai/privacy)
before using work that cannot be shared publicly. Use sketches or references
you are allowed to upload. A private setting, where available, is not a
substitute for permission to use the source material.
