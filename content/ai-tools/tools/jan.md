## Where it fits

Jan's desktop app is a candidate for local model chat. Its [documentation](https://www.jan.ai/docs/desktop) also covers connected providers and distinguishes desktop, web, and agent products. Choose the desktop local workflow deliberately if that is your goal; the same brand name does not establish where a request runs.

## A useful first trial

Use a small model and a short non-sensitive brief. Ask for a summary, then check omissions and invented claims against the input. Repeat with the same prompt if you change models, so the comparison remains meaningful.

Before enabling connectors or agent features, review what files, commands, or external services they can access. Start without private repositories, customer documents, or production credentials.
