## Test the Guide With a Demo Account

Scribe's [features page](https://scribe.com/features) shows how a screen
capture becomes a guide. Scribe's [AI page](https://scribe.com/scribe-ai/)
describes AI help with titles and descriptions. In a demo workspace,
capture how to save a fictional equipment request as a draft. Check
whether someone with the intended permissions can find the right button
and tell a saved draft from a submitted request.

## Recheck After the Interface Changes

Keep a note of the interface version or review date. When the application
changes, ask a teammate to follow the published guide and check steps
against a fresh run. The [process guide practice pack](/use-cases/check-an-ai-process-guide-against-a-workflow/)
helps you practice spotting missing prerequisites and misleading steps.

Before recording or sharing work material, read [pricing](https://scribe.com/pricing),
[security guidance](https://scribe.com/security), and the
[privacy policy](https://scribe.com/legal/privacy). Start with fictional
data and check screenshots, text, links, and who can see the guide.
