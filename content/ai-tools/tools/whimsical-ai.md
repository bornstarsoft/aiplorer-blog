## Walk Through Two Paths Before Sharing

Whimsical describes [drafting editable flowcharts](https://whimsical.com/diagrams)
with its [built-in agent](https://whimsical.com/learn/ai/whimsical-ai).
Start with a fictional equipment request: a coordinator checks whether the
request is complete, returns incomplete requests to the sender, and asks
the inventory lead to check stock for complete requests. Trace a complete
request and an incomplete one against the brief. If the chart invents an
approval rule, remove it or note it as an open question.

## Revisit the Diagram When the Process Changes

Keep the brief next to the chart. If the handoff changes, check the
edited path and any exceptions it affects. Use the
[process guide practice pack](/use-cases/check-an-ai-process-guide-against-a-workflow/)
to rehearse checking a draft against the written workflow.

Before using internal material, review [pricing](https://whimsical.com/pricing),
sharing permissions, [privacy](https://whimsical.com/terms/privacy), and
[AI terms](https://whimsical.com/terms/ai-terms).
