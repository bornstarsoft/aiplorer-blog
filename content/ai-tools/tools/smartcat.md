## Review a Reused Sentence in Its New Context

Smartcat's [AI translation guide](https://help.smartcat.com/ai-translation-overview/)
describes using previously reviewed translations alongside new AI
translations. In a fictional workshop handout, the sentence "The guide
will be available next week" stays the same, but the new paragraph limits
access to registered attendees. Use the [translation editor guide](https://help.smartcat.com/editor-functionalities-overview/)
to understand where reused wording appears. Review the full paragraph so
the translation does not promise access to everyone.

## Check the New Edition Before Releasing It

Keep the source edition and note which translations you rechecked. On
the next update, compare dates, eligibility, and promises in both
versions. The [meaning-preserving rewrite practice pack](/use-cases/check-an-ai-rewrite-without-changing-the-promise/)
offers a separate review key for checking the same details.

Before using real documents, review [pricing](https://www.smartcat.com/pricing/),
[privacy](https://www.smartcat.com/legal/privacy-policy/), and who can
open the project and its original files.
