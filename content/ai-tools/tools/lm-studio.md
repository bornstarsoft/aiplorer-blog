## Where it fits

LM Studio offers a desktop way to work with downloaded language models. Its [app documentation](https://lmstudio.ai/docs/app) covers model management, chat, and document workflows. The wider product also includes Bionic and connected features; this page focuses on choosing a local-model setup.

## A useful first trial

Download a model appropriate for your hardware, then ask it to rewrite a short paragraph without changing the facts. Compare the result against the original. If you try document chat, use a sample file without private information and check every answer against the source.

The [offline guide](https://lmstudio.ai/docs/app/offline) explains which tasks can run after model files are downloaded. Offline-capable core chat should not be confused with a promise that every optional feature stays on your computer.

## Before connecting anything

Review selected endpoints, cloud options, extensions, and file permissions. Keep generated code under normal review and testing. Check [app privacy](https://lmstudio.ai/app-privacy), [terms](https://lmstudio.ai/app-terms), and [pricing](https://lmstudio.ai/pricing) for current conditions.
