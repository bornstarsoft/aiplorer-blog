## Check the App Message With Realistic Sample Values

Lokalise's [AI Translations guide](https://docs.lokalise.com/en/articles/8011393-ai-translations)
describes using project terminology; its
[placeholder guide](https://docs.lokalise.com/en/articles/1400511-lokalise-universal-placeholders)
explains how placeholder formats can differ by platform. Try a fictional
message such as "Your pickup is ready at {location}." Use the placeholder
format your project expects. Check the translated sentence with two
fictional location names to see whether the value appears correctly and
the message still fits.

## Repeat the Check When the Source Message Changes

Keep the original text, the approved product term, and a rendered
example. Use the
[translation glossary practice pack](/use-cases/check-an-ai-translation-against-a-product-glossary/)
to rehearse checking a term in context. Review [pricing](https://lokalise.com/pricing/),
[privacy](https://lokalise.com/privacy-policy/), and project sharing
before importing unpublished or customer-facing material.
