## Start With What Changed Since the Last Session

In this fictional example, a community center uses a one-page handout to
train volunteers to reserve equipment. The reservation rules and the
downloadable PDF have both changed. The old handout passed its checks, but
that result does not carry over to the new rules or file.

Start with the exact handout revision, the approved procedure, and the
learning objective. Use a demo account and fictional records for the
practice. If nobody can find the old test notes, treat the checks below
as a new baseline.

### 1. Walk Through the Normal Case and One Exception

Ask a teammate who did not write the handout to follow it without extra
instructions. A normal booking should end with a reservation number. If
the requested item is unavailable, the learner should stop and request
help instead of substituting another item. Check both paths against
the approved procedure, including who can make exceptions.

**Try it:** [Check an AI process guide against a workflow](/use-cases/check-an-ai-process-guide-against-a-workflow/).

### 2. Ask the Learner to Do the Task

If the goal is to make a reservation, ask the learner to reserve a demo
item and show the confirmation. A question about where to find the
reservation button only tests recall. Write down what counts as success
before the learner starts so the next reviewer can apply the same check.

**Try it:** [Check an AI study guide against learning objectives](/use-cases/check-an-ai-study-guide-against-learning-objectives/).

### 3. Check the File Learners Will Actually Receive

Open the distributed file, not just its editable source. Verify that
links, headings, and key instructions are usable in the format learners
will receive. For example, check the reading order of a two-column PDF
with the relevant assistive technology. Record the file version, methods,
and outcomes. Leave untested checks marked as untested.

**Try it:** [Check an AI accessibility summary against an audit log](/use-cases/check-an-ai-accessibility-summary-against-an-audit-log/).

## Example: The Source Is Fixed but the PDF Is Not

The workshop draft now tells volunteers what to do if an item is
unavailable. In the exported PDF, that instruction is read after the
confirmation step instead of before it. **Hold the PDF.** Correct the
reading order, export again, and repeat the affected checks on the new
file. A correct source document is not evidence that the export passed.

## Keep the Checklist With the Revision

Save the decision and its evidence next to the approved revision. At the
next session, rerun any checks affected by a change to the procedure,
objective, or file format. If it is unclear which checks a revision
affects, rerun all three. Keep learner details out of the checklist.
