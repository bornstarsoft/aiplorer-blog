## Check the File the Recipient Will Open

A PDF can look right on screen and still fail the brief. In this exercise, compare an AI-generated export plan for a fictional community handbook with the delivery requirements. Check what the recipient needs to print, select, and open.

## Get the Pack

Give the AI only the test input. Use the separate key to review its answer, then use the worksheet to compare a second run.
