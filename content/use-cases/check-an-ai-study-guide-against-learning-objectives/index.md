## Does the Task Teach the Skill?

A clear study guide can still prepare learners for the wrong task. Compare an AI-written guide for a fictional library search workshop with the actual learning objectives. Check whether the guide adds barriers, asks learners to practice the right skill, and explains what counts as passing.

## Get the Pack

Give the AI only the test input. Check its findings against the separate review key, then use the worksheet to compare a second run or another tool.

| LEARN-01 | The guide does not add a prerequisite absent from the brief. |

| LEARN-03 | The passing criterion includes every required part of the response. |
