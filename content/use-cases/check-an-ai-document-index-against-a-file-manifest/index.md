## Check What The Packet Really Contains

An AI-drafted index can look complete while pointing to an older file or listing something that was never approved to share. Compare three entries in a fictional client packet with its file manifest. No real files need to be opened or shared.

## Check Three Entries

| Case | Look for | What to verify |
| --- | --- | --- |
| INDEX-01 | A valid filename with the wrong version | Match the approved version exactly. |
| INDEX-02 | A file in the folder but outside the sharing scope | Leave internal-only material out of the client index. |
| INDEX-03 | A required item listed as ready without evidence | Flag the missing attachment and hold the packet. |

Separate what is present from what is approved. An expected filename does not prove that the file exists.

## Retest With The Same Manifest

Reuse the same draft index and source manifest. Compare which errors each run catches and whether it invents a substitute. For real work, verify sharing scope and the actual attachment list with the packet owner before sending anything.
